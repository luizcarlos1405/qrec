Project picker

What qrec shows with nothing to open (SPEC §4.4, docs/GUI.md G§4.12). It shipped on 2026-11-09, built from X2's and S21's patterns with no frame. These boards are its design, at the window's default 760×640, on the approved chrome: X3's minimal header, the artwork's quiet swamp, X3 and S18b themselves.

What's on the board

  1. Project picker: the recent projects, most recent first. One selected, one hovered, one whose folder is gone. Variants: searching (matched letters in bold), no match, folders still being looked at, a folder that wouldn't open.
  2. No projects: the first run, and qrec started in an empty folder (Start a project here).
  3. New project: the field empty, a name typed (Creates …), a name with no projects folder set, a folder that's taken.
  4. X3 · Open another project: X3 when qrec wasn't started with --project, with one more way out.
  5. Settings › Project: the All projects group under Canvas.

What changes from the build

  • Paths are mono (mono-sm, DESIGN Typography: file paths), shortened with ~.
  • The selected row gets the 1 px accent stroke every selected row has (DESIGN Shapes). Its texts turn text.
  • Remove from list (×) shows on the hovered and selected rows only, and always on a gone one, where it's the only thing to do.
  • A gone folder wears the missing-media pattern: triangle-alert and Folder not found in warning-text, the name in disabled-text.
  • "Recent" heads the list, with the count.
  • Search matches are bold, as in the palette (C34).
  • The empty list is an empty state (C31): the quiet swamp, a storybook title and one sentence, instead of a grey line in the middle of the window.
  • New project: the hint's path in mono, Create with its Enter key cap, a taken folder shown on the field (invalid stroke) and in record-text.
  • Checking a folder shows a small spinner next to Checking….

Questions for you

1. Is 760×640 the right default size?It's the build's DEFAULT_SIZE. The list fits about seven projects before it scrolls.
2. Should the selected row show its key?The hint bar already says Enter opens. A key cap on the row would repeat it.
3. May two windows on different projects record at once?Still open (G§4.12). It doesn't change these boards, but "Open or create a project…" from a recording window depends on it.
