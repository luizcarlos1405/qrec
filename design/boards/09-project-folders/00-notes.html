Project folders

The single projects folder becomes a list of named folders, one of them the default (SPEC §4.4, §6.4). The CLI is built: qrec folders [add|rename|default|rm] and qrec create NAME --in FOLDER. Until these boards are approved, the GUI keeps the approved 08 boards and works on the default folder only.

What's on the board

  1. New project · folder menu: beside the field, in 📁 work ▾, the default to begin with. The hint names the folder. Variants: a name typed, the menu open (the default marked, Make default on the hovered row, Add a folder…), another folder chosen, a path typed (the menu dims: a path goes where it says), no folders yet (no menu, the Add a project folder… link), a taken folder.
  2. Settings › Project · project folders: the Projects folder row becomes a list in the All projects group. Each row: name, path (mono), Default badge or Make default on hover, rename (✎) and forget (×). Add folder… above. Variants: renaming in place, no folders.

Behavior

  • Choosing a folder in the picker is for this project only; the default changes only through Make default (menu or Settings) or qrec folders default.
  • Add a folder… opens the folder chooser; the new folder is named after its last part (videos, videos 2 when taken) and can be renamed in Settings. In the picker it becomes the chosen folder.
  • Forget (×) never touches the disk, so it asks nothing: a toast says Forgot clients. The folder is untouched. Forgetting the default makes the first one left the default.
  • Keys: Alt+↓ opens the menu from the field; in it ↑ ↓ Enter Esc.

Questions

1. Should a chosen folder in the picker become the default?Recommended no: the default stays put, and Make default is one click away in the menu.
2. Should Add folder ask for a name first?Recommended no: the folder's own name is almost always right, and renaming is in Settings. Asking adds a dialog to every add.
3. Should rows be reorderable?Recommended no for now: the order is the order added, and the default is what matters.
